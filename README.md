# Frontend Projects Showcase

### HTML · CSS · JavaScript · React · Accessibility · Responsive UI

This repository collects three major frontend projects completed for **INFO6150 Web UI/UX Engineering**, showing my progression from semantic multi-page websites to interactive JavaScript interfaces and a larger React-based single-page application.

Rather than serving as a course hand-in repository, this project set is best viewed as a small frontend portfolio focused on:

- semantic HTML and accessible UI structure
- responsive and adaptive layout design
- JavaScript-driven interactivity and validation
- component-based frontend development with React

---

## ✨ Featured Projects

### 🌐 [Project 1: Horse World](./project1)

A responsive multi-page website built with semantic HTML and CSS.

**Highlights**
- multi-page site structure with shared navigation and footer patterns
- card-based homepage layout using grid and flexbox
- accessible form design and POST submission flow
- responsive layout and content organization across viewports

### 🐱 [Project 2: Cats Power the Internet](./project2)

An interactive frontend project focused on responsive navigation, accessibility, modals, and JavaScript validation.

**Highlights**
- adaptive desktop/mobile navigation with a hamburger menu
- skip link and keyboard-friendly interaction patterns
- single `<dialog>` modal triggered from multiple actions
- JavaScript-based form validation and submission flow

### 📦 [Final Project: Find My Stuff](./final)

A React-based single-page application for tracking household items and quickly finding them later.

**Highlights**
- component-driven React UI
- add, browse, search, filter, and sort item workflows
- modal details view and profile/settings interactions
- theme switching and accessibility-focused navigation
- chat-style item lookup experience
