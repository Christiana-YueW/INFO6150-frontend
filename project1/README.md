# Project 1: Horse World

### Semantic HTML · Responsive Layout · Multi-Page Website

Horse World is a multi-page frontend website built with HTML and CSS to demonstrate semantic page structure, responsive layout techniques, and accessible form design.

This project focuses on building a polished static site experience without JavaScript-heavy interaction, emphasizing layout fundamentals and content organization.

---

## 📌 Overview

The site includes:

- a homepage with card-based content sections
- an about page with long-form content
- a registration page with a structured form
- repeated header/footer patterns across pages
- internal navigation and external reference links

---

## ✨ Key Frontend Skills Demonstrated

- semantic use of `header`, `main`, `footer`, `nav`, `section`, and `article`
- responsive page layout with CSS Grid and Flexbox
- multi-column card layouts
- consistent visual design across multiple HTML pages
- accessible labels, alt text, and content structure
- server-backed form submission flow via Express

---

## 🗂 Project Structure

- `public/index.html` — homepage
- `public/about.html` — about page
- `public/register.html` — registration page
- `public/styles.css` — shared styling
- `server.js` — static server and form POST handler

---

## ▶️ Run Locally

```bash
npm install
node server.js
```

Then open:

```text
http://localhost:3000/
```

---

## 🎯 Project Focus

This project is best understood as a foundation piece in semantic HTML/CSS frontend development, with emphasis on page structure, layout systems, responsive design, and accessible form construction.
